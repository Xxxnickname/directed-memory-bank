# L1 原子事实

每日一个文件：`YYYY-MM-DD.md`。不存在则新建，存在则**追加**。

## 写入格式

```markdown
- 类型：<规则变化 | 已完成动作 | 验证结果 | 遗留问题>；状态：<confirmed|probable>；置信度：<0.00-1.00>；来源：<用户消息原文 / 会话文件:行号 / 命令输出>
  - 一句话事实，可被验证。
```

## 准入

- 只写**已验证**的事实：做了什么、关键决定、方案或规则变化、遗留问题。
- 不写闲聊、不写未确认推断；未确认的进 `controlled-memory/candidates.md`。
- 每条必须有来源，否则无法审计，也无法被安全推翻。
