# 全局指令（记忆库入口）

本文件是记忆库的规则入口。宿主每次会话开始必须先读本文件，再读 `memory-bank/_index.md`。

## 会话红线

- **默认只读**：未经用户明确批准，不得修改任何文件、不得提交或推送。
- **有疑惑必问**：对命令或意图有疑问时先反问，理解到 100% 再执行；不确定时只给方案不动手。
- 记忆写入属于"用户已授权"的动作：用户说"更新记忆 / 记忆存档"即视为批准写入记忆库。

## 记忆库分层（L0→L3）

- L0 原始证据：`L0-raw/YYYY/MM/`（完整会话，只读保存）
- L0 可移植记录：`L0-portable/YYYY/MM/`（脱敏 JSONL，换工具或换机器优先迁移）
- L0 清单：`L0-manifest/manifest.jsonl`（来源、归档范围、两层归档路径）
- L1 原子事实：`L1-facts/YYYY-MM-DD.md`（已验证事实、规则变化、遗留问题，带来源与置信度）
- L2 场景/项目/技能：`L2-scenarios/`、`L2-projects/`、`L2-skills/`
- L3 画像：`L3-profile/user-profile.md`（稳定背景、长期偏好、固定规则）
- 受控记忆：`controlled-memory/`（候选、纠错、复核）

`L0-raw` 只作为输入源；日常检索使用 `L0-portable` 与 L1-L3。

## 受控自动学习

流程固定四步：**提取 → 去重/冲突检测 → 状态判定 → 写入或候选化**。

- 直写 L1：已验证的项目事实、已完成的动作、明确的规则变化，必须带来源证据。
- 进候选区：用户可能的偏好、性格或能力推断、单次情绪、临时计划、未确认的长期目标；至少两次一致证据，或用户明确说"以后记住/一直这样"，才可升级。
- 进纠错区：用户明确纠正或新旧冲突；记录旧值、新值、证据、影响范围，禁止静默覆盖。
- 进复核区：时间敏感、低置信度、长期未验证；复核前不当作当前事实。

状态：`confirmed`（明确确认）、`probable`（多次行为支持）、`observed`（单次观察）、`rejected`（用户否定）、`expired`（过期保留）。

事件与画像分离：一次性经历写 L2，不因一次经历改变 L3。

## 检索顺序

```text
规则 / 纠错  >  当前项目状态  >  已确认画像  >  相关 L1/L2  >  少量候选
```

`rejected` / `expired` 不主动加载。

## 记忆存档命令

用户说「记忆存档」「保存记忆」「更新记忆库」「存档并结束」「记到记忆里」时：

1. 把本次会话要点追加到 `L2-scenarios/YYYY-MM-DD.md`（不覆盖）。
2. 有进行中任务则更新 `L2-projects/` 对应文件。
3. 按受控自动学习规则提炼 L1 / L2 / L3，并推进水位线。
4. 回复「已存档：<摘要>」。

## 语义检索（本地）

```powershell
pwsh -File <MEMORY_ROOT>\scripts\memory-search.ps1 -Query "<意图>" -Top 8
```

记忆或笔记有新增/修改后，重建索引：

```powershell
python <MEMORY_ROOT>\scripts\memory_search.py index
```

## 敏感信息

API Key、密码、Cookie、Token 一律用 *** 打码，绝不写入任何记忆文件；发现误写立即删除。

## 新会话恢复

用户提到「继续上次 / 看看我的进度 / 之前聊过」时，先读 `L3-profile/user-profile.md` 与 `L2-projects/` 中在进行的任务，再按 `L0-manifest/manifest.jsonl` 追溯到原始证据。
