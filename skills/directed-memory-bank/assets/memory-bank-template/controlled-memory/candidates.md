# 候选记忆

> 单次观察、模型推断、未确认偏好放这里。**低权重参考，不改变任何行为规则。**

## 升级条件

至少两次独立一致证据，或用户明确说"以后记住 / 一直这样"，才可升级到 L1/L3。

## 记录模板

```yaml
- id: cand-YYYY-MM-DD-NNN
  内容: <一句话>
  类型: <偏好 | 能力 | 性格 | 计划 | 目标>
  状态: observed        # observed | probable
  证据: <用户消息原文 / 会话文件:行号>
  首次观察: YYYY-MM-DD
  最近观察: YYYY-MM-DD
  置信度: 0.00-1.00
```
